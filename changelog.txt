1.5.1
- Fixed release packaging to generate and verify the addon and repository ZIPs before creating a GitHub Release.
- Fixed stable and beta release asset attachment to use the generated versioned ZIPs, addons.xml, and MD5.
- Improved release output cleanup to prevent stale artifacts from being published.

1.5.0
- Added a remote-friendly home screen with Live TV, Favorites, Recently Watched, TV Guide, Search, Catch-Up, and VOD entries.
- Added stable channel/programme favourites with migration and synchronization for the existing PVR favourites list.
- Added a non-sensitive Recently Watched history with a configurable limit and clear action.
- Added cached channel/programme search with Unicode-safe ranking and favourites priority.
- Added a native Kodi TV Guide presentation with EPG caching, programme state, catch-up actions, and programme context menus.
- Added backward-compatible playback quality, adaptive streaming, maximum-resolution, and maximum-bitrate settings.
- Added safer playback error messages and redacted playback diagnostics.
- Fixed XML escaping in addon.xml and fork-owned stable/beta distribution metadata.
- Added semantic-version, XML, ZIP, generated-metadata, MD5, distribution-URL, and archive validation.
- Hardened the GitHub Actions stable/beta publication workflow.
- Enabled TLS certificate verification and protected local manifest/developer-tool access.
- Fixed web-login storage namespace detection, logout cleanup, and unsafe legacy favourite decoding.
